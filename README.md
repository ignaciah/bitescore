# bitescore
A restaurant discovery and review app built with Next.js and 14 Firebase
markdown

## Features

- 🔐 **Authentication** - Email/password & Google login
- 🏪 **Restaurant Listings** - Browse restaurants with filters
- ⭐ **Reviews & Ratings** - Add reviews and rate restaurants
- 📱 **Responsive Design** - Mobile-first approach
- 🔍 **Search & Filter** - Find restaurants by cuisine, price, etc.
- ♥️ **Favorites** - Save favorite restaurants

## Tech Stack

- **Next.js 14** - React framework with App Router
- **Firebase** - Authentication, Firestore, Storage
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **React Query** - Data fetching (optional)

## Getting Started

### Prerequisites
- Node.js 18+ 
- Firebase account
- Git
